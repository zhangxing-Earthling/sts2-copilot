## 下一步（按优先级）

### P1 战斗求解器

- 枚举本回合出牌顺序（手牌 ≤10、能量 ≤4）
- 目标：击杀 > 最少掉血 > 保留资源
- 输出最优序列与预计掉血；替代当前“集合背包”
- 验收：与游戏内实际掉血误差 ≤ 1（无随机因素时）

### P2 决策落盘

- `reward_pick`：对比选牌前后牌组
- `map_pick`：对比 `_visitedMapCoords`
- `potion_use` / `card_play` 精确化：读 `CombatManager.History`

### P3 DeepSeek 复盘

- 局末 digest（指标 + top-K 决策点）
- 结构化输出 + 证据 id 校验
- 规则 patch 提案，不自动合并

### P4 非战斗界面

- 商店：商品/价格/删牌
- 事件：选项与条件
- 营地：升级/回血
- 宝箱/遗物三选一

## 不做

- 自动打牌/输入注入
- 修改游戏内存或存档
- mod 形式
- 用 LLM 做实时战斗决策（延迟/成本/幻觉）
