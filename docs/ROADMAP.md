## 下一步（按优先级）

### P1.5 实机校准

- 在 `turn` 日志结构化记录求解器预测（序列/预计掉血/能量/未建模牌）
- 用 JSONL 对比每回合预测掉血 vs 实际掉血，算 MAE
- 补遗物/药水/抽牌/敌人 buff 意图；把未建模牌逐步加入
- 验收：连续 20 场无随机战斗误差 ≤1；超时率 <1%
- 通过后，把求解器输出接到地图 DP 的掉血估计

### P2 决策落盘

- `reward_pick`：对比选牌前后牌组
- `map_pick`：对比 `_visitedMapCoords`
- `potion_use` / `card_play` 精确化：读 `CombatManager.History`

### P3 DeepSeek 复盘

- 局末 digest（指标 + top-K 决策点）
- 结构化输出 + 证据 id 校验
- 规则 patch 提案，不自动合并

### P4 非战斗界面

- 商店：商品/价格/删牌
- 事件：选项与条件
- 营地：升级/回血
- 宝箱/遗物三选一

## 不做

- 自动打牌/输入注入
- 修改游戏内存或存档
- mod 形式
- 用 LLM 做实时战斗决策（延迟/成本/幻觉）
